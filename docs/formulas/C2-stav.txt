Stav u tlačítka Kontrola (C2) po obnovení Dotaz1.

Nepoužívat vzorec s JEDINEČNÉ / LET / počet řádků.
Dotaz StavKontroly porovná soubory v TabNove s tabulkou TabArchiv.

1. Data → Načíst data → Z jiných zdrojů → Prázdný dotaz
2. Rozšířený editor → vložit stav-kontroly.m
3. Když hlásí, že nezná TabNove: vlevo v editoru je název vašeho dotazu
   (často Dotaz1) — v první řádce `Nove = TabNove` ten název dosaďte
4. Název dotazu: StavKontroly
5. Zavřít a načíst do… → Existující list → Přehled, buňka X1
6. C2 smazat, napsat =X2  (formát Obecný)
7. Sloupec X: šířka 0
8. Vlastnosti dotazu StavKontroly: aktualizovat při otevření, bez na pozadí

Když vyskočí Firewall: Možnosti dotazu → Ochrana osobních údajů →
Vždycky ignorovat úroveň ochrany osobních údajů.
