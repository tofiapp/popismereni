# Mereni – slouceni

Makra **nesmi** byt v OneDrive (Excel je tam blokuje).

1. Novy sesit → import `SloucitMereni.bas`
2. Alt+F8 → **Nastavit** → uloz jako  
   `Documents\MereniSloucit.xlsm` (**ne** do OneDrive)
3. Vyber slozku `MD1_rozdeleno` (sync OneDrive)
4. Tlacitko **Sloucit** → zapise `Souhrn_mereni.xlsx` do te slozky

Kolega cte jen `Souhrn_mereni.xlsx` (bez maker).
